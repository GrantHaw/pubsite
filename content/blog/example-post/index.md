This is the overview for a post. It's written in `index.md`, and it's the first thing people see when they open the folder.

Everything else in this folder shows up in the file list. Markdown files render as pages, and PDFs open in a viewer.

## Things you can do in markdown

- Headings, lists, and **bold** text
- Links like [my GitHub](https://github.com/GrantHaw)
- Code blocks:

```bash
nmap -sV 10.0.0.0/24
```
